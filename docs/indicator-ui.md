# Indicator 像素工位伙伴

原版 SenseCAP Indicator，480×480 电容触摸屏。YOYO 负责自然语言交互；Indicator 提供桌面表情、真实状态和本地番茄钟。界面参考 Worker Smart Planter：炭黑底、奶油白信息卡、鼠尾草绿主色，搭配柔紫和水蓝；主角是像素 CRT 盆栽，加入桌面小物、像素图标和便签式排版。查看[固件原生动画](previews/indicator-worker.gif)与[页面总览](previews/indicator-worker-overview.png)。

这里描述的是 `firmware/indicator/` 的原生绘制实现。旧浏览器 HTML 保留为早期交互原型，不代表新版像素界面；下方的原生预览直接运行固件绘图代码并导出帧。

## 页面与手势

**可爱表情 → 今日状态 → 信息屏 → 照片屏 → 番茄钟。**

- 开机停在“工位小绿洲”，轻点像素盆栽进入今日状态。向左滑进入下一页，向右滑返回上一页，首尾不循环。
- 顶部返回键返回上一页；打开主题、硬件操作或确认页时，先关闭最上层页面。滑动离开确认页不会发送操作。
- 右上角“换个心情”在任何页面打开 8 个主题；选中立即应用并存入 ESP32 Preferences，下次开机保留。
- 手指抬起后才识别点击。横向滑动至少 60 px；触摸通信错误、多指或越界会取消这一段手势，直到真正抬手。
- 今日状态用四张卡显示土壤湿度、空气温度、空气湿度和泵/灯状态；硬件操作在单独面板内。切主题、翻页、计时不会触发浇水、灯光或打印。
- 浇水和打印先打开确认页；再次明确点击确认，且当前连接、新鲜度和设备能力仍满足条件，才提交一次指令。浇水显示配置的秒数，不推算毫升；打印展示固定 ASCII 便签内容。停泵直接提交，不增加确认步骤；网络停泵不是物理急停。
- 信息屏显示连接、采样距今、空气和 UV 原始数值，以及在手机上使用 YOYO 的提示。没有水位、可见光照度、流量、墙上时钟或 YOYO 在线状态数据，因此不照搬参考图中的水箱百分比、光照百分比、120 ml、日期时间或“已连接手机”。

土壤百分比需要有效且已标定的数据；空气湿度不能代替土壤湿度。缺失或未校准的数据用 `--`，保留的旧读数和旧设备状态会标注。空气和 UV 只显示原始 ADC，不转换成空气质量结论、lux 或光照百分比。

主角具有黑色屏幕、温柔眼睛与腮红、顶部双嫩芽、浅色机壳和小底座。双眨眼、嫩芽轻摆、1 px 呼吸起伏、星点明暗与杯口蒸汽都是陪伴装饰，不代表植物生理状态、设备在线或 YOYO 情绪判断。只有新鲜状态确认泵正在运行时，操作页才显示运行动态；动画不代表测得的出水量或完成比例。`accepted` 表示受理，`completed` 表示软件任务完成；打印完成仅代表串口字节已发送。结果未知时不自动重发，界面要求现场核对后才能解除新动作锁定；停泵不受这项锁定限制，但仍需网络与设备能力可用。

| 主题 | 配色 |
| --- | --- |
| 工位花园 | 炭黑、奶油白、鼠尾草绿与柔紫 |

八套主题使用同一 CRT 像素电脑盆栽，改变深色背景、浅色卡片、机壳、杯子和书本的配色，部分主题带小徽章或侧饰。页面顺序、读数意义和操作位置保持一致，具体像素外观以当前固件原生截图为准。切换主题会保留计时状态；只有主题编号写入 Preferences。

## 番茄钟

提供专注 25 分、短歇 5 分、长歇 15 分。支持开始、暂停、继续、重置；运行或暂停期间需先重置才能更换时长。计时不依赖 Wi-Fi，翻页和换主题不会重置。完成后停在完成状态，不自动开始下一轮。

当前只在屏幕上提示完成；没有蜂鸣、手机推送或后台日程提醒。重启设备会清空当前计时，主题选择会保留。当前 MCP 工具不提供主题/番茄钟控制，也不向屏幕推送 YOYO 对话。

## 导入自己的照片

照片页默认显示空相册。当前版本支持把 1–4 张本地图片编入固件；不是手机实时传图，也不自动访问相册。需 Python 和 Pillow。

在项目根目录执行（替换为自己的图片路径）：

```powershell
python tools/pack_indicator_photos.py 'C:\Photos\窗边.png' 'C:\Photos\山野.jpg'
python tools/build_indicator_font.py --font .tools/fonts/NotoSansSC-Regular.otf
.\tools\build.ps1 -Target indicator
```

工具按 EXIF 方向旋转、居中裁切为 **400×280 RGB565**，去除 EXIF 等元数据，仅保留像素和文件名标题。每张像素约 224 KB，最多四张。照片使用前后按钮切换，左右滑动仍切换功能页。

生成的 `firmware/indicator/include/photos.local.h` 已被 Git 忽略；若把原图放入 `firmware/indicator/assets/photos/`，该目录也被忽略。照片像素会进入编译后的固件，因此分享私人固件前需检查内容。删除 `photos.local.h` 并重新构建即可恢复空相册。

源字体下载位置、许可与重生成说明见 `firmware/indicator/assets/fonts/README.md`。常规构建已经自带生成的中文字库，不必下载字体；修改中文标题或照片标题后才需重新生成。屏幕中文不等于热敏打印机支持中文，当前小票仍为 ASCII。

## 验证与实机检查

```powershell
.\tools\test-indicator-ui.ps1
python -m unittest discover -s tests -p test_indicator_assets.py -v
python tools/build_indicator_font.py --check
```

可移植测试覆盖页面边界、触摸释放/滑动隔离、无效触摸锁定、计时暂停与时钟回绕、主题与计时独立。图片测试覆盖方向、RGB565 字序、透明背景处理和错误输入保留旧包。

新版原生预览需先安装固件固定版本的 Arduino_GFX 依赖，并具备 Visual Studio C++ Build Tools、Python 和 Pillow。在项目根目录执行：

```powershell
.\tools\render-indicator-ui.ps1
# 可传入 -Python 'C:\path\to\python.exe'
```

工具通过桌面测试边界运行生产 `main.cpp`、主题、中文字形和照片绘图代码，并使用固定版本 Arduino_GFX 栅格算法生成 480×480 RGB565 帧。输出位于 `build/indicator-preview/`，包括 PNG、动画 GIF 和多主题拼图；`manifest.json` 记录来源文件哈希和预览限制。输入为明确未连接的未知状态，不连接硬件、不发送指令，也不填充演示传感器读数。

[旧 HTML 预览](previews/indicator-companion.html)是独立实现的早期原型，可参考导航意图，不能用它判断新版固件的布局、图形或帧率。原生截图更接近实际绘图结果，但仍不模拟 LCD 时序、PSRAM/DMA、背光、触摸硬件或实机速度；GIF 为 256 色，PNG 保留导出的像素颜色。

烧录后仍需核对五页手势、八主题可读性、照片颜色、计时跨页继续、确认页取消/发送隔离，以及网络失效时的提示。当前没有本次新版 UI 的实机验收结果，生成预览不代表已经烧录。
