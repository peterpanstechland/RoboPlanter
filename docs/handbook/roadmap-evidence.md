# 功能状态与实机依据

本页于 **2026-11-13** 整理；最近一轮实机确认记录截至 **2026-11-04**。软件实现、接口回包和实际出纸／出水分别记录。

| 继电器与水泵 | Relay v1.2 空载吸合释放通过；用户确认独立 12V / 150mA 水泵短暂出水 0.5 秒后停止 | 流量、低水保护与最终安装的完整检查 |
| 共享番茄钟 | 主控 HTTP 开始／暂停／继续／结束通过，Indicator 显示共享状态 | 手机语音控制与蜂鸣器听音；主控断电不恢复当前计时 |

当前接线以[最新硬件连接](../wiring.md)为准：打印机使用 BLE，所有打印机 TTL 线断开；超声波使用 D7，旧 D8／D9 接法已停用。此前电平异常的具体原因没有确诊，不能据此认定某一块板或引脚已损坏。

## 已有实现、仍需完成整段体验

- **五种场景日签：**打卡、午饭、会议、休息和低电量；默认自动打印、可关闭，并有冷却与去重。设备端会议签和屏幕打印已通过，完整手机触发矩阵待验收。
- **两板配网：**屏幕已有配置两台设备的向导及进度显示；实际更换网络、重启恢复的完整流程待验收。
- **提示音与提醒：**D1 无源蜂鸣器程序和系统提醒映射已有实现；实际听音、建立提醒与到点触发待验证。
- **NFC：**专门进入当前 Skill 的深链接仍未验证。
- **其他硬件与植物知识：**Device Kit 和地区化作物参考为离线原型，接入新设备仍需驱动、传输和实机验证。

## 版本与接口说明

本地 Skill 文件和公开下载包为 **1.0.3**，不据此推断荣耀平台或手机当前安装的版本。当前 Skill 未开放语音启动浇水。历史 MCP／MQTT 网关是可选辅助路径，本地 BLE 交互不以它们为前提；A2A 尚未实现。

屏幕生命条、心情与加速成长是互动状态，真实物候依赖实际观察；塔罗用于娱乐和反思。网页上的浇水、灯效和计时预览只作用于浏览器。
