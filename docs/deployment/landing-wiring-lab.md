# Landing page 三维接线小工坊

日期：2026-10-25。入口：`/roboplanter/#wiring-lab`。

## 实现

- 独立的轻量 Three.js 程序化教学模型，沿用页面已经使用的本地 r180 运行时；不加载 45MB Tripo 外观模型，不调用 Tripo 或其他付费生成服务。
- 依据附件 V1.0 板卡照片和原理图保留 XIAO 的 4 个 Grove / 4 个 Servo 识别关系；Indicator 的两个口归属 RP2040。布局、装饰走线及模块造型为教学简化，不是工程 CAD 或实际电路走线图。
- 九条教学路线：水位、SHT31 候选、WS2812、打印机、土壤、外置水泵驱动、空气模拟采集，以及 Indicator ADC / I²C 扩展候选。每条包含供电、信号、验证三步和实现状态。
- 自由查看支持拖动、俯视与拆层；练习模式支持拖动插头、点选接口或按钮代操作。接错时解释目标接口；接对后吸附、文字反馈、纸种子动效与进度记录，支持重试及逐件继续。
- 练习进度只存在当前页面内存，不是设备接入状态。供电和信号光点为教学路径，不是实时电流。未发现、配对、连接或控制真实硬件，没有设备请求。
- 奶油色工作台、柔和阴影、PCB 走线/丝印、金属屏蔽罩、插座卡扣、外设托盘与小表情。新增四个文本资产合计约 68KB，不包含照片、原始附件、凭据或私有设备配置。

## 边界

水位模块需按实际水箱选型，水位驱动/低水位停泵尚未实现；Indicator Grove 的 RP2040 采集和内部转发尚未实现。模拟练习完成不表示真实接线或实机验收完成。执行器电源、逻辑电平、驱动及传感器型号仍以实物核对为准。
