You clock out. I'll keep growing.

Some workdays are a long queue of things that need attention. I wanted one of those things to be alive, small and worth slowing down for. RoboPlanter is a desk garden that combines a real plant, a pixel companion and a tiny paper ritual.

Talk to YOYO on an HONOR Robot Phone, check calibrated plant readings on a SenseCAP Indicator, and keep a little ticket with your plant's state, three handwritten to-dos and a randomly drawn tarot card. The blocky, Creeper-inspired enclosure holds the plant, the screen, the phone and a thermal-printer outlet in one object.

This is a working hardware prototype with a documented DIY path. The most recent field confirmations are from November 4, 2026. The English documentation was prepared on November 13; it does not claim new physical tests.

One plant, three interfaces

The phone handles natural conversation. The Indicator supplies a persistent touch interface. XIAO is the state and action controller, so both interfaces use the same calibration and action results.

  • Robot Phone / YOYO ↔ XIAO: encrypted BLE through the official Skill tool.
  • Indicator ↔ XIAO: authenticated HTTP on the same 2.4 GHz Wi-Fi network.
  • Soil probe → Indicator RP2040 → Indicator ESP32 → XIAO: ADC, internal UART and HTTP upload.
  • XIAO → EM5826H printer: direct BLE carrying ESC/POS bitmap and cut commands.

The phone pairs with XIAO, not with the Indicator. The two boards need no external UART or I²C wire between them, and a cloud server is not required for this local path.

The hardware inside

The controller is a Seeed XIAO ESP32-S3 Plus on XIAO Robot Board V1.0; it is not the XIAO Sense camera variant. The display is a SenseCAP Indicator D1 with its internal ESP32-S3 and RP2040.

A Grove SEN54 supplies air temperature, humidity, particulate matter and VOC index. A capacitive probe measures relative soil moisture; a Grove Light Sensor v1.2 provides ambient-light ADC readings. A Grove Ultrasonic Ranger v2.0 measures water-surface distance. Thirty WS2813 pixels indicate state or provide white fill-light indication. A Grove Relay v1.2 switches the prototype's independent 12 V, 150 mA pump circuit. An EM5826H thermal printer provides BLE and automatic cutting.

SEN54 replaces the earlier DHT20 and analog air-quality sensor. It does not measure CO₂ or NOx. The complete BOM separates hardware, software and supporting supplies.

Build the enclosure and wire the current revision

Print Body8, Body9 and Body16, one each. Body20 is a reference volume and must not be printed as a product part. Check slicing, supports, mounting fits and liquid/electronics separation on your own printer.

  • SEN54: SDA GPIO5, SCL GPIO6; independent 5 V VCC and 3.3 V I²C signals.
  • Ultrasonic SIG: UART/J10 RX, D7, GPIO44; independent 3.3 V and common ground; white wire unused.
  • Light sensor: SERVO3, D0, GPIO1 at 3.3 V.
  • Relay signal: SERVO1, GPIO42; pump power remains on its independent load circuit.
  • WS2813 DIN: RGB/J7, GPIO40, with a suitable 5 V supply and the configured brightness ceiling.
  • Soil probe: Indicator RP2040 GPIO27 at 3.3 V.
  • Printer: BLE; USB and all TTL signal wires disconnected.

M2 is unused. GPIO43 must not feed the printer, because ESP32 ROM boot logs can print as text. GPIO44 is now reserved for the ultrasonic signal. Power down before changing wiring, and never feed 12 V into a Grove power pin. The current wiring guide supersedes old D8/D9 arrangements.

Bring up the firmware one link at a time

Clone the repository and follow the English build tutorial. The projects pin Espressif32 6.12.0, ArduinoJson 6.21.5 and GFX Library for Arduino 1.4.7 for the Indicator. Build the XIAO and Indicator targets separately; install the RP2040 soil responder separately too.

Use your own private configuration, preserve a working device's settings and start with actuators disabled. First prove startup and a read-only state request. Add sensors, calibration, phone reads and printing before commissioning the liquid circuit. Wi-Fi association alone does not prove the screen's HTTP authentication is correct.

How the YOYO Skill talks to XIAO

The package contains SKILL.md plus a BLE contract and an acceptance checklist. The root prompt gives the companion a warm, concise voice and maps approved intents to the official ble_send_command tool. XIAO still validates every command; a prompt is not a device driver or a security boundary.

For first pairing, show the six-digit code on the Indicator and pair the phone with XIAO's RoboPlanter name. The system Bluetooth bond supplies authorization. No permanent Wi-Fi, HTTP or MQTT password is placed in the Skill. Ordinary reconnect keeps the bond and displays whether a request reached the controller.

Read soil first, then temperature/humidity as needed. A response such as “Soil:65% calibrated” is reported as a percentage; raw ADC is reserved for explicit diagnostics. Missing, stale and uncalibrated are different states, and valid 0% is still a reading. Actions have a request ID: if a reply is lost, query that same action instead of creating another print job.

The local Skill is version 1.0.3 and its instructions are currently Chinese. That version does not establish what is installed on the phone, and these English examples are not a claim that every language setting has been tested. See the English engineering API for UUIDs, official tool JSON, commands, HTTP endpoints and response semantics.

Calibrate the plant, then make a little ritual

Capture actual dry and wet references in your substrate from the Indicator's calibration page. The resulting percentage is a relative scale, not laboratory volumetric water content. Measure full, low-water stop and empty distances in the installed tank; moving the probe means rechecking those references.

Green LEDs mean the controller and Indicator are ready. Asking the screen for fill light makes all 30 pixels white; turning it off returns to the status layer. Light thresholds are adjustable and saved on the device.

The screen's pixel plant starts as a seed and offers mint, basil, rose and succulent identities. Its game health and desk mood are expressive state, not measurements of botanical health. A game-watering action does not secretly run the physical pump.

The tiny ticket is the ending

A ticket carries a plant-computer logo, plant state, three handwritten checkboxes and a random card from all 78 tarot cards, upright or reversed. The selection is frozen between preview and printing. Tarot is entertainment and a reflection prompt, not a prediction.

On this EM5826H, 32-row bitmap bands flattened the vertical proportions. An A/B paper test showed that the 128-row path preserved the square and circle. The complete 384-dot ticket now prints with normal proportions and automatic cutting, and matches the Indicator's seven-page preview.

Printr inspired the idea of small printed daily rituals. The plant character, calibrated sensing, Indicator preview and XIAO BLE workflow are this project's implementation.

What works, and what comes next

Field-confirmed results include calibrated phone soil reads, bond-preserving reconnect, green → white → green on all 30 LEDs, D7 ultrasonic readings changing with a moved target, and complete screen-to-paper tickets with correct proportions and cutting. The prototype also previously produced water for one 0.5-second command and stopped.

The full voice scene-print and focus-timer acceptance matrix, audible buzzer, complete real Wi-Fi-change workflow and a specific NFC Skill link still need checks. Voice-started watering is not enabled in the current Skill. Printing bytes is not a paper-presence or cutter-position sensor; final mechanical output still needs observation.
