# 工位搭子互动展示

此目录是 [公开展示页](https://peterpanstechland.github.io/roboplanter/) 的唯一源文件。通过 `tools/sync_docs_site.py` 同步到文档站的 `static/roboplanter/`；不需要修改站点全局 CSS 或安装前端依赖。

```bash
python3 -m http.server 8767 --bind 127.0.0.1 --directory web/experience
# 浏览器打开 http://127.0.0.1:8767/
```

页面文档链接使用部署站点的绝对路径；独立本地预览时会是 404。完整站点构建后再验证教程导航。

## 实现与交互边界

- 首页以 Creeper 头花盆的程序化方块场景为主角，`voxel.css` 统一草方块、像素边框与合成台视觉。官方产品图、来源与校验信息位于 `assets/hardware/sources.json`，点击可跳转 HONOR 和 Seeed 产品页。
- “旧存档”折叠区展示 Tripo v3.1 生成的静态外观模型：先加载约 319 KB 的预览图，用户点击后才创建预览 iframe 并下载约 45 MB 的 GLB。返回图片会卸载 iframe；它不是实机扫描、制造 CAD、设备状态或自动照料效果。
- `model-viewer/` 使用本地 Three.js **0.170.0** 与同版本 GLTFLoader / OrbitControls / RoomEnvironment，原 MIT 许可保留在其 `vendor/three/LICENSE`。与下方 0.180.0 角色演示在独立 iframe 内隔离；无运行时 CDN 或 Tripo API 调用。模型加载失败或 WebGL 不可用时保留预览图和重试入口。
- 公开模型与预览图只从 `assets/all-in-one/` 分发。`manifest.json` 记录大小和摘要；不复制账户、积分记录、原始 Tripo 任务响应、临时下载地址或本机配置。
- Three.js **0.180.0** 从官方 npm 发布包取出，仅包含两个固定 ES module 文件和原 MIT 许可证；页面不使用运行时 CDN、不连接设备、不收集输入。
- 程序化几何角色、光照、阴影与手势旋转；用户可选择四种角色文案。
- WS2813 方形灯带支持关、柔绿、呼吸、流动和彩虹网页预览。10 个示意光点不代表真实灯带安装位置，不发送硬件请求。
- 150 个方形点精灵以自定义 GLSL 绘制，使用原创程序化像素纹理，不分发 Minecraft 游戏材质。
- “像素子弹时间”固定动画时间并环绕观察；它是网页效果，不是实机动作同步或实体屏幕功能。
- “给搭子一口水”只有本地动画与文案反馈，不能调用泵。按钮旁保留模拟说明。
- 3:4 海报为本地 Canvas 生成的 1200×1600 PNG，显式标注概念演示和非实机拍摄，不自动发到任何平台。
- WebGL 不可用时显示静态角色，文档和海报仍可用。遵循 `prefers-reduced-motion`，页面隐藏时暂停帧循环，渲染上限约 30 fps、DPR 上限 1.75。

方块花盆网页场景为程序化预览，实际外壳由用户制作。Minecraft / Creeper 名称归其权利人所有；RoboPlanter 是独立硬件项目。

## 发布前验收

检查桌面和 390px 手机宽度，无横向溢出；四种心情选中态与文案一致；浇水重复点击有冷却；定格/继续状态正确；Esc/关闭按钮能关闭海报对话框；PNG 尺寸为 1200×1600；弱动效/无 WebGL 有可读退路；控制台没有错误。完整站点还要检查每个教程链接。

一体机区还要确认：首次打开页面未请求 GLB；点击后可显示加载进度、旋转、缩放和重置；关闭后恢复图片并卸载 iframe；断开模型请求时仍能看图与重试；减少动态效果时禁用自动转台。页面隐藏或相应展示区滚出视口时暂停渲染。手机宽度布局检查不等于真实手机的 GPU、温升或网络性能验收。

社媒海报的文字、状态标签和真实/模拟提示不能因裁切而消失。性能数值是实现预算，不是所有手机实测结果。

## 当前接线教学 · 2026-10-29

wiring-data.js为九个接口/预留位置的数据源；wiring-scene.js将模块、信号与电源路径分别表现。SEN54独立5V，环境光/超声波独立3.3V；打印TX在SERVO4/GPIO7，返回在UART/GPIO44；继电器在SERVO1且负载空着。Indicator ADC接土壤。两个预留接口练习只确认留空，不显示插线。M2不使用，旧DHT20/Air/UV不再出现。图形简化，不按外形推断针序；逐线接法以docs/wiring.md为准。
