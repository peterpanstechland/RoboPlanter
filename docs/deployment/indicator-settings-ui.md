# Indicator D1 字体与设置界面更新

记录日期：2026-10-24。**本轮已完成编译、COM13 上传哈希校验和 20 秒启动观察；屏幕观感、背光和真实 Wi-Fi 流程待用户实机验收。** 不能把此前版本的触摸反馈视为本轮设置功能已经通过实测。

本页记录新增字体、语言、Wi-Fi 与背光设置。[首次刷写与恢复记录](indicator-first-flash.md)及[Worker UI 版本记录](indicator-worker-ui.md)保留各自的历史，不由本页覆盖。

## 设备范围

用户已确认实物为 **SenseCAP Indicator D1**，使用 480×480 屏幕、ESP32-S3 与 RP2040。本轮目标仍是 ESP32-S3 应用，不更换 RP2040 固件。

D1 **没有内置 CO₂ / VOC 传感器**；温湿度测量需要外接传感器，例如按相应型号和接线要求使用 Grove 扩展，见 [Seeed 官方型号说明](https://wiki.seeedstudio.com/SenseCAP_Indicator_Native_Firmware/)。本轮没有把 Grove 传感器接入或读取功能实现为新的本机数据源。主界面花盆读数仍来自 XIAO 返回的有效状态；未知、未启用或未收到的读数不会补成示例数值。

## 屏幕操作

| 入口 | 操作与结果 |
| --- | --- |
| 任意主页右上角齿轮 | 打开设备设置；再次点击关闭。进入设置会关闭底层控制与确认面板。 |
| 设置 → 中文 / English | 即时切换主界面、状态说明、确认面板和设置子页的语言；成功保存后重启保留。语言名称、品牌、SSID 和单位按其自身含义显示。 |
| 设置 → Wi-Fi | 查看扫描、连接中、已连接或失败状态；点击网络进入密码页。 |
| Wi-Fi → 刷新 | 异步扫描 2.4 GHz 网络，最多显示信号较强的 10 个不同 SSID，每页 5 个，用左右按钮翻页。扫描期间不能点选结果。 |
| 密码页 | `abc` / `ABC` 切换大小写；`#+= 1` / `#+= 2` 切换数字与符号页。支持空格、删除；密码只显示星号和长度。 |
| 密码页 → 连接 | 加密网络接受 8–63 个 ASCII 字符或 64 位十六进制 PSK；开放网络不用密码。连接由后台任务执行，不阻塞触摸界面。 |
| Wi-Fi → 恢复默认连接 | 清除用户保存的 Wi-Fi 凭据，重新使用固件配置中的默认 SSID / 密码；不是恢复整机出厂镜像。 |
| 设置 → 屏幕亮度 | 点击滑条，或用 `−` / `+` 每次调整 5 个百分点。范围为 5%–100%，只在抬手后生效；成功保存后重启恢复。 |
| 设置 → 关于设备 | 显示 D1、双 MCU 和外接传感器说明，不显示未经读取的本机环境数值。 |
| 左上角返回 | 密码页返回网络列表；其他设置子页返回设置首页；设置首页返回原主页面。 |

设置覆盖层会消费点击与滑动，不把手势传给下方的浇水、灯光或打印按钮。点击动作要求触摸起点和终点均在同一目标内。设置界面使用按钮翻页，不用横滑切换主功能页。

当前没有手动输入隐藏 SSID 的入口；使用扫描结果选择网络。SSID 限长为 32 字节，中文 SSID 按原始字节交给连接接口，显示截断不会修改连接目标。

## 字体与背光

字体沿用本地 Noto Sans SC，通过离线生成器分别生成 **16、24、32、48、64 px 的原生单色字形**。每档包含相同的项目字符子集；大字不再是把 16 px 位图简单放大。变宽高位图及真实偏移保留了 `g / y / p / q / j` 的下伸笔画和 `j` 的负左边距。

旧 `draw` / `width(scale)` 保留原有字符前进宽度和 `18 × scale` 行距；新增 `drawSized` / `widthSized` 使用各字号的原生宽度。主要标题和设置标签使用原生 24 px，辅助说明仍有 16 px，大号数字使用 32–64 px。新增文案后必须重新生成并检查字库覆盖；正常固件编译使用已生成的头文件，不在设备启动时栅格化字体。

背光由板级 LEDC PWM 驱动，亮度设置限制为 5%–100%，避免界面被调至完全不可见。保存操作交给后台任务；保存失败时显示相应提示。本机像素预览不模拟实际背光亮度或 PWM 效果。

## 网络、保存与实际限制

Wi-Fi 凭据在成功关联并取得 IP 后才保存到本机 NVS；失败尝试不覆盖上一份成功保存的连接。语言与亮度也通过后台任务写入 NVS。存储不可用时不能把界面上的即时变化视为已经持久保存。

密码不进入状态快照、SSID 文本或日志。密码页返回、关闭或连接请求被后台受理后，会清空 UI 的 RAM 输入缓冲。若请求因忙碌等原因尚未被受理，页面保留星号输入并显示错误，可以直接重试；退出仍会清空。后台连接所需的有界凭据副本由网络模块管理，这与清空 UI 输入缓冲是不同阶段。

**Wi-Fi 连接成功不等于花盆可操作。** 当前花盆 HTTP 链路有明确的网络限制：只有连接的 SSID 与本次固件编译配置的 `PLANTER_WIFI_SSID` 完全一致，才允许向 `PLANTER_BASE_URL` 发起设备请求。项目默认地址是 `http://192.168.4.1`；实际配置以该次构建的 `config.h` / `local_config.h` 为准。界面不会修改设备令牌、HTTP 地址或这个 SSID 限制。

因此可以在设置页连接普通 Wi-Fi，但不会在任意路由器网络上向固定 `192.168.4.1` 发送花盆令牌。匹配 SSID 也只说明满足网络条件，**不证明 HTTP 鉴权、状态读取或执行器已经成功**；仍需主界面的有效、新鲜状态和设备能力许可。切换网络后，旧读数不能继续当作当前可操作的依据。

其他边界：

- 热敏小票目前仍使用固定英文 ASCII 内容；语言设置只改变界面与说明，不把打印机固件变成中文字库。中文界面会明确说明当前小票为英文。
- 字库覆盖项目界面文案，不包含全部汉字。任意中文 SSID 中未收录的字可能显示 `?`；连接时仍保留完整原始 SSID 字节。长名称用省略号显示。
- 无效、离线和过期的传感器状态继续按原规则显示，设置页的 Wi-Fi 图标不能替代花盆状态判断。
- 原生截图直接运行生产绘制代码，但不验证 LCD 时序、实机触摸、无线射频、NVS 实物写入或硬件帧率。

已执行的独立检查包括：6 项 Python 字形/覆盖测试、40 项原生字体绘制检查、39 项设置 UI 检查（其中包含 12 张截图输出检查，另覆盖忙碌时保留输入与重试）、17 项真实主界面手势与操作断言，以及 252 项设置与网络检查（118 项后端状态检查、134 项真实客户端代码的模拟网络回归）。

网络回归覆盖 STOP 排队和发送时拒绝切网/扫描、重复 STOP 不覆盖唯一请求、完成后释放保留、普通切网立即失效旧能力、旧浇水请求不发往新网络，以及各类后台初始化失败。STOP 未完成时连接请求会返回忙碌，密码页保留输入。所有这些网络检查均使用模拟 radio / HTTP / NVS / RTOS，不向真实执行器发送动作。

字体检查覆盖下伸笔画、不裁负边距、32 px 不是 16 px 方块放大、48/64 px 中文不静默回退、旧宽度兼容。设置检查覆盖抬手生效、按钮两端命中、中文 SSID 字节、密码清空与长度约束、开放网络、扫描与分页隔离。这些检查使用本机替身接口，不连接电脑 Wi-Fi 或真实设备。

项目根目录的复现入口：

```powershell
python tools/build_indicator_font.py
python tools/build_indicator_font.py --check
.\tools\test-indicator-font.ps1
```

Python 需要 Pillow；原生绘制检查需要 Visual Studio C++ Build Tools 及项目固定版本的 Arduino_GFX 依赖。设置独立测试的 PPM 位于 `build/indicator-preview-v2/settings-host/`，其中网络名称和状态是明确的测试夹具。整体预览生成 524 帧、8 个 GIF 与 14 张对照图，已查看中英文页面，来源哈希与当前 UI 代码一致。具体输出及来源哈希见 `build/indicator-preview-v2/manifest.json`。
