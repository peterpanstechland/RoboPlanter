# 1.0.2 验收

固件编译和主机测试不代表手机蓝牙工具已通过。联调记录放在 docs/deployment/yoyo-companion-v2.md；未经记录的步骤保持未验收，不把这份清单当成功证据。

1. Indicator开启两分钟配对；手机输入屏幕PIN，连接状态变“手机已安全连接”。重连无需PIN；未配对手机不能查询或操作。
2. YOYO“读取工位状态”依次读取soil与env，按S回包的校准百分比、E回包的温湿度合并回复；与Indicator相近时间读数比较，允许整数四舍五入及采样时间差。单问土壤时只查询soil，默认不播报ADC；0%是有效值，未校准/无效/过期/超时分别如实提示，不补零、不复用旧值。遮住光敏传感器时ambient明显变化。
3. “打开灯”“关灯”各一次，回包与实际灯光一致；回复不朗读协议。
4. “开始1分钟番茄钟”，Indicator共享计时；“暂停”“继续”“还剩多久”“结束”语义正确。结束提示音仅开关开启才响；断开手机仍计时。
5. “早上好，上班打卡”自动一张；追问“今天加油”不重复。最长14中文字的场景命令能完整写入，出纸比例正常并切纸。
6. “关闭自动打印”后说“今天开了很多会”不出纸；明确“打印一张会议幸存签”仍可以出一张；重启后开关保留。
7. “10点半提醒我点外卖”：以真实系统时间判断日期，使用官方日程提醒，结果可在手机日历核对；不另外重复建闹钟；提醒本身不打印、不假装自动起AI对话。
8. “给植物浇水”：明确本技能尚未开放语音启动浇水，不启动继电器；紧急停泵命令独立最高优先。
9. 断线、工具超时、打印恢复锁、结果MISS：不换id重放，不捏造成功。
10. “就想吐槽，别打印”“简短点”“那个继续说”“谢谢去忙了”：遵循上下文，无多余设备操作。
11. Indicator 顶部 Wi-Fi 图标直达连接中心；Wi-Fi、HTTP、手机 BLE 分段显示，普通重连保留绑定，重新绑定另需确认。配对码过期、主控离线、切换网络时隐藏旧码；网络重连不删除保存配置。
12. 手机重连后读取状态，屏幕显示请求到达主控；单独问候不触发这项硬件成功提示。故障时先区分技能入口、HTTP 与 BLE，不笼统要求删除重配。

2026-11-04连接恢复修订：两板编译和烧录通过，主控返回保留绑定重连 completed，结果接口可查询；用户确认现有手机技能正常返回读数，Indicator 显示“请求已到主控”。设备侧确认加密认证、通知订阅和工具处理记录。此记录只验收该条重连读数路径，不表示本地1.0.2已发布到荣耀，也不覆盖全部故障注入和动作场景。
