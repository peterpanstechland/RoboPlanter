# YOYO 日常交互与首次连接

更新：2026-11-03。当前新入口为 **RoboPlanter工位小芽 1.0.0**（`roboplanter-workmate`），已私有上架，用户确认普通问候能正常回复。发布状态见[平台记录](../deployment/honor-platform-status.md)。旧版本曾通过首次绑定和“读取工位状态”；新入口的读取和打印仍待复验。

手机使用与开发者平台同一手机号的荣耀账号，在 **YOYO → 技能库 → 我的技能 → 私有技能** 安装新名称的条目，并打开新对话。先说“你好”，再说“读取工位状态”，最后只触发一次打印。普通问候也报服务不可用时，先处理技能入口，不要反复清除蓝牙绑定。

## 连接中心与断线恢复（2026-11-04修订）

直接点 Indicator 顶部 **Wi-Fi 图标**，或打开“设置 → 花盆连接”。页面逐段显示屏幕的 Wi-Fi、屏幕到 XIAO 的 HTTP、手机到 XIAO 的 BLE，附最近更新时间。手机与主控直接配对，屏幕只是配对码的显示端。

| 屏幕显示 | 下一步 |
| --- | --- |
| Wi-Fi 连接中／自动重试倒计时 | 等待当前20秒尝试结束；掉线后30秒自动重试，也可手动重新连接。保存的配置保留。 |
| 已联网但不是花盆网络 | 点“连接花盆网络”，或在网络设置选择原来已配置的网络。 |
| 花盆暂未响应 | 核对 XIAO 供电和目标地址，再点“立即检查链路”；此按钮只读状态。 |
| 配对认证失败（HTTP） | 核对两块板的设备令牌；重新绑定手机不会修复这个错误。 |
| 已绑定，手机按需连接 | 正常待机。打开手机“工位小芽”，说“读取工位状态”，无需再次输入码。 |
| 手机已连接，等待技能请求 | 蓝牙认证已通过，仍需一次技能读数验证。说“你好”不验证硬件。 |
| YOYO 请求已到主控 | 主控已处理工具命令。手机中的实际回包才决定业务是否成功。 |
| 手机配对超时 | 查看手机弹窗；已有绑定时先点“重连手机（保留绑定）”。 |

“YOYO 与场景小票”里将 **重连手机** 和 **重新绑定手机** 分开。普通重连只释放手机链接并恢复广播，保留绑定、Wi-Fi、校准及打印机设置；然后在手机重新进入技能并读一次状态。换手机或保留绑定重连仍失败时，才使用带确认的“重新绑定手机”。新配对码显示倒计时；过期或屏幕失去主控状态时隐藏，不能继续输入旧码。

本地 Skill 1.0.2已补充同样的排障话术；代码包已更新不表示平台或手机已安装这一版。无论使用哪个版本，重连不自动重放超时的打印或浇水请求。

**2026-11-04真机验收：** 两板更新后，用户按“保留绑定重连 → 现有手机技能读取工位状态”操作，确认正常返回读数，屏幕显示请求到达主控；主控记录确认已加密连接、通知已订阅、工具请求已处理。Wi-Fi配置及旧手机绑定均保留。本轮未用清除绑定作为重连前提。

## 换Wi-Fi与两板配网

在Indicator顶部Wi-Fi图标进入“无线网络设置”，选择“选择Wi-Fi，配置两台”。密码只在设备上输入一次，页面显示五阶段进度；主控试连成功后保存，再由屏幕接入并确认通信。首次迁移仍需要两板共享设备令牌和专用恢复热点密码，使用`tools/pair_indicator.py`可生成私有屏幕配置。配置成功后的换网、重启不再要求修改源码和刷机。详见[配网工程接口](system-api.md#21--两板统一配网与地址发现2026-11-04)。

“仅设置屏幕Wi-Fi”只切换屏幕；连接咖啡馆等其他网络不代表已连接花盆。联网、手机蓝牙绑定和Skill入口是独立状态，不用重新绑定手机来处理Wi-Fi错误。

## 2026-11-04百分比回传已验收

XIAO的普通soil回包现在直接写明例如`Soil:65% calibrated`，旧入口常用的desk也改为`S65% T25.1C H49%`这类带单位摘要；默认结果不夹带ADC。原始值可经soil_raw单独查询，原S/K格式保留在soil_v2/desk_v2作为诊断兼容。用户已确认手机现有入口现在返回百分比，并与Indicator接近；不用重新校准或重新配对。

本地Skill1.0.3及待导入包已更新，本轮未修改荣耀平台条目。以下1.0.1审核记录为历史过程，不代表手机当前版本。

## 校准后的土壤湿度

1.0.1已提交私有发布审核，手机获得更新后，单问土壤会使用主控返回的校准百分比；完整工位状态再读取空气温湿度。该百分比与Indicator使用相同的干湿两点标定，是相对湿度刻度，不是实验室体积含水率。仅有效且已校准时播报百分比，未校准提示去屏幕校准，过期或失效提示暂无有效数据；0%本身可以是有效结果。原始ADC只在明确询问时给出。审核中不表示手机已经采用新版。

## 找到六位配对码

1. 两板供电并接同一2.4GHz Wi-Fi，Indicator“设置 → 花盆连接”显示花盆可用。
2. 打开“YOYO与场景小票”，点 **“显示六位配对码”**，开启两分钟窗口。
3. 手机系统蓝牙选择对应RoboPlanter，输入 **Indicator该页面显示的六位码**。不是手机锁屏密码，不在技能文件里。
4. 主控确认绑定后，打开手机Skill，说“读取工位状态”。

绑定存储在设备，设计上只需首次登记；主控重启保留绑定已验证，手机跨重启重连仍待单独验收。窗口过期时在Indicator重新开启并使用新码，旧码不再有效。2026-11-03 16:12，修订固件已实际完成手机加密认证并保存绑定；新入口的读取和打印仍需分别确认。

一次仅支持一个BLE命令连接，调试App应先断开。“读取技能文件异常”先排查Skill安装/版本/有效入口，与输入蓝牙PIN是不同步骤。

## 手机再次索要配对码时

手机与 **XIAO Robot Board** 蓝牙配对；Indicator 通过 Wi-Fi 操作 XIAO，并显示其六位码。手机不是与 Indicator 配对。打印机是 XIAO 的另一条 BLE 连接。

若手机已丢失旧绑定，但主控仍显示“已配对”，在支持恢复功能的固件上操作：

1. 手机系统蓝牙里忽略旧 `RoboPlanter-A994`，暂时关闭手机蓝牙。
2. Indicator 打开 **设置 → 花盆连接 → YOYO 与场景小票 → 修复手机配对**。
3. 阅读确认页后点 **确认重新配对**。手机尚未断开时，此按钮会等待，不会中途改绑。
4. 主控确认清除旧手机密钥和登记信息后，Indicator 显示新六位码。
5. 重新开启手机蓝牙，在两分钟内选择 `RoboPlanter-A994`，输入屏幕上的新码。
6. 回到 **RoboPlanter工位小芽**，先读取工位状态，再测试一次打印。

取消确认不会清除绑定。恢复只处理旧手机的绑定，保留 Wi-Fi、传感器标定、自动打印偏好和打印机配置；正常重连无需使用此功能。没有新码或出现失败提示时，不应猜测配对码。此功能通过已鉴权的本地 HTTP 操作，不向 YOYO 开放清除绑定命令。

## 五种自动场景日签

用户已选择命中场景后自动打印，默认开；可在同一设置页或语音中关闭。

| 表达 | 场景 | 短句示例 |
| --- | --- | --- |
| 早上好，上班打卡 | checkin | 今天慢慢来也行 |
| 今天吃什么外卖 | lunch | 先吃饭，再拯救世界 |
| 今天开了很多会 | meetings | 会议结束，脑袋下班 |
| 心累，想摸会鱼 | rest | 休息一下也算进度 |
| 今天不想上班 | lowbattery | 低电量也值得被照顾 |

每轮最多一张，同场景五分钟内最多一次。“别打印这次”覆盖当前触发；“以后别自动打印”保存关闭偏好；明确“打印一张”可手动打印。引用、否定、复述和“谢谢”不再出纸。

小票含Logo、场景短句、真实有效状态快照、三行可勾选手写待办、**完整78张牌随机一张及正逆位**。屏幕预览打开时抽一次并固定；语音场景在命令被接受后生成一次，不声称已经预览其牌面。塔罗为娱乐提示，不是事实预测。

设备端会议幸存签、Indicator预览与纸面一致已验收，手机自动触发待验收。超时只查原ID，不自动重印或重新抽牌。详见[工位日签](daily-ticket.md)。

## 番茄钟与声音

共享计时由XIAO负责，1–120分钟，默认25分钟。手机断开不取消计时；主控断电清零。Indicator同步状态，不打断正在进行的设置和确认。

D1内置 **RP2040 GPIO19无源蜂鸣器**，不是语音喇叭。180ms短音协议已部署，默认关闭，可在番茄钟页开启并保存；听音待确认。YOYO语音从手机输出。

系统提醒与番茄钟不同。日期、时区或“今天10:30已经过去”需澄清；只有明确“每天/工作日”才建重复提醒。工具确认前不宣称设置成功；提醒不等于自动打开AI、下单或打印。

## 对话节奏

小芽默认一至两句接住当下处境，再按需执行。“会议开麻了”可以说“今天是会议在上班，你在陪跑。”；“别建议，就想吐槽”就继续听，不强塞任务。只读查询或单独设备控制不会附送小票。回复以业务结果为准，不把工具已发送当成已出纸。
