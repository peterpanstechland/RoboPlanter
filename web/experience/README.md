# 工位搭子互动展示

此目录是 [公开展示页](https://peterpanstechland.github.io/roboplanter/) 的唯一源文件。通过 `tools/sync_docs_site.py` 同步到文档站的 `static/roboplanter/`；不需要修改站点全局 CSS 或安装前端依赖。

```bash
python3 -m http.server 8767 --bind 127.0.0.1 --directory web/experience
# 浏览器打开 http://127.0.0.1:8767/
```

页面文档链接使用部署站点的绝对路径；独立本地预览时会是 404。完整站点构建后再验证教程导航。

## 实现与交互边界

- Three.js **0.180.0** 从官方 npm 发布包取出，仅包含两个固定 ES module 文件和原 MIT 许可证；页面不使用运行时 CDN、不连接设备、不收集输入。
- 程序化几何角色、光照、阴影与手势旋转；用户可选择四种角色文案。
- 360 个 Gaussian falloff 点精灵以自定义 GLSL 绘制；这是柔和粒子视觉效果，**不是训练或重建的 3D Gaussian Splatting 模型**。
- “定格这一秒”固定动画时间并环绕观察；它是网页效果，不是实机动作同步或实体屏幕功能。
- “给搭子一口水”只有本地动画与文案反馈，不能调用泵。按钮旁保留模拟说明。
- 3:4 海报为本地 Canvas 生成的 1200×1600 PNG，显式标注概念演示和非实机拍摄，不自动发到任何平台。
- WebGL 不可用时显示静态角色，文档和海报仍可用。遵循 `prefers-reduced-motion`，页面隐藏时暂停帧循环，渲染上限约 30 fps、DPR 上限 1.75。

所有角色形状与文案均为本项目编写；当前外形是产品概念，不能作已制造外壳、量产产品或商城图片。

## 发布前验收

检查桌面和 390px 手机宽度，无横向溢出；四种心情选中态与文案一致；浇水重复点击有冷却；定格/继续状态正确；Esc/关闭按钮能关闭海报对话框；PNG 尺寸为 1200×1600；弱动效/无 WebGL 有可读退路；控制台没有错误。完整站点还要检查每个教程链接。

社媒海报的文字、状态标签和真实/模拟提示不能因裁切而消失。性能数值是实现预算，不是所有手机实测结果。
