# YOYO 主交互接入

RoboPlanter 的主入口是 YOYO：用户说话，YOYO 理解意图，通过 MCP 查询或操作盆栽，再用设备返回结果回答。Indicator 是状态显示与本地操作终端。按用户原方案，当前优先实现“平台 LLM 智能体 + 自有 MCP”，BLE Skill 保留作手机近距离直连的备选。

## 文件

- [智能体提示词](agent-prompt.md)：配置到平台 LLM 智能体，描述角色、工具使用、动作结果和陪伴交互。
- [交互验收场景](acceptance-scenarios.json)：人工在 YOYO 上逐条试验；这些是预期行为，不是已经通过的模型测试。
- [MCP 桥接服务](../mcp/README.md)：六个实际工具及本机运行方式。
- [设备协议](../../docs/device-protocol.md)：XIAO 的状态、命令和结果查询。

## 调用关系与网络

```text
用户语音/文字 → YOYO / 平台 LLM 智能体 → 自有 MCP 服务 → XIAO HTTP
                                                        ↕
                                                SenseCAP Indicator
```

图中的箭头表示调用职责。**目前的代码可以在本机测试工具与 HTTP 通信，但还没有部署成荣耀平台可访问的服务。** MCP 进程必须能访问 XIAO 的 `192.168.4.1`；电脑可连接 XIAO 热点，本机 MCP 客户端用 stdio 或回环 HTTP 测试。电脑需要同时连互联网时，应另外保留一条可用网络链路，不能假设连上无上网能力的 XIAO 热点就同时具备互联网。

荣耀的远程 MCP 调用方不能访问用户电脑的 `127.0.0.1`，也不能直接访问花盆的 `192.168.4.1`。下一阶段需要受控的远程设备通道或手机本地桥接方案。当前服务只提供本地验证入口，没有开放公网、创建隧道、注册插件或发布智能体。端 MCP 虽有控制台入口，其 SDK 与本地桥接协议尚未取得；不把普通 HTTP 服务冒充端 MCP。

## 平台配置顺序

1. 先按 MCP 服务说明完成本机 `tools/list`、状态查询和模拟设备测试，随后用实际 XIAO 验证只读状态。
2. 确定能同时满足“平台可访问”和“能到达设备”的部署链路，配置服务鉴权；本地回环地址不是平台服务地址。
3. 在“我的插件”中按官方 MCP 指南接入该链路提供的服务，检查实际发现的六个工具和参数。不要把 HTTP `/api/v1/state` 地址填成 MCP 服务地址。
4. 在 LLM 模式智能体中绑定插件，并使用 `agent-prompt.md`。工具名称如被平台添加前缀，按实际工具名映射。
5. 先验证只读对话，再用已完成供电/驱动检查的灯带、水泵和打印机验收操作。语音成功必须同时有工具日志和设备反馈，不能只凭 YOYO 说“成功了”。

资料：[插件配置](https://developer.honor.com/cn/doc/guides/101645)、[MCP 接入指南](https://developer.honor.com/cn/doc/guides/101724)。平台的独立 Skill 与 LLM 智能体是不同入口；当前提示词用于已绑定 MCP 插件的 LLM 智能体，不伪装成已经打包、安装的独立 Skill。

## BLE Skill 备选的实际条件

荣耀的 `ble_send_command` 支持 `ack_type="ack"` 和 `expect_response=true`，分别控制 GATT 写确认和设备业务响应等待。当前固件特征支持 WRITE + NOTIFY，不能照搬附件中的 `no_ack` 与不等回包配置。设备名称应使用实际广播名称，不添加未公开的扫描工具。

官方文档同页对 `result_code` 的说明存在 0 与 200 两种成功值，真机需核实实际工具版本，并验证 `response` 中的设备业务结果；仅工具写入成功不能证明泵已完成。文档未给出自动协商 MTU、长写、跨调用保留连接或 APIKey 注入的明确保证。

现有 16 字符令牌下，`S|token|uv` 已为 21 字节，土壤查询 23 字节，两秒浇水命令约 31 字节，超过默认 ATT MTU 下常见的 20 字节载荷。必须先在手机上验证完整请求和响应，再生成可用 BLE Skill；本轮不通过删除设备鉴权或猜测秘钥变量名来绕过这个问题。来源：[官方蓝牙工具与参数](https://developer.honor.com/cn/doc/guides/101781)。

## 交互边界

NFC 贴用于选择盆栽和打开入口，不把碰触解释为浇水授权；指定 YOYO Skill/智能体的直达链接尚未验证。屏幕目前显示设备状态，没有对话文字和情绪动画。打印机首版仅支持 ASCII；中文对话由 YOYO 完成。自动浇水、定时提醒、多设备长期记忆等后续功能不混入首版验收。
