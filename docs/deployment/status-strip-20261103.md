# 30 颗灯带：在线状态与白色补光

2026-11-03，当前台架为 Grove WS2813、Robot Board RGB J7 / GPIO40。用户选择以主控与 Indicator 在线作为绿灯条件；手机和打印机按需连接，不计入该条件。

## 行为

- 30 颗灯珠，RMT 输出，保持原亮度上限 24/255。
- 没有开启补光／主动灯效时：主控网络已连接且 Indicator 最近上传的数据年龄不超过 10 秒，显示低亮绿色；否则显示低亮琥珀色。
- 默认开灯为白色补光，优先于在线状态色；关补光恢复当前状态色。环境光自动开灯也使用白光。原呼吸、流动、彩虹仍可显式选择。
- Indicator 中英文按钮和自动阈值说明改为补光语义，字体重新生成。
- 新增 HTTP 字段 `light.display_mode`、`pixel_count`、`brightness_limit`、`status_enabled`；`light.on` 继续表示补光／主动灯效，不把在线绿灯误报为补光开启。
- 状态灯为可选配置 `ROBO_ENABLE_STATUS_LIGHT`，通用默认值为 0，现场私有配置为 1。

## 验证与部署

- XIAO 和 Indicator 的现场配置均编译通过。
- 主控测试：498 项控制器检查、13,563 项灯效检查，以及现有传感器、校准、自动补光、陪伴控制测试通过。新增检查覆盖全部 30 颗颜色、状态切换、白光优先、关闭恢复和动画时序。
- 设置页面 89 项检查通过。实际主界面与独立设置页面均生成中英文预览，补光文字无截断。
- 两板均先验证身份和原应用，再备份应用及 NVS / OTA 数据；仅更新 `0x10000` 应用区，不清空设置区。

用户现场确认：**30 颗绿→白→绿正常，屏幕触摸正常**。因此本次 Indicator 触发补光、关闭后恢复在线绿灯及全灯珠输出已通过实物验收。手机语音开关灯、琥珀色实物观察和长期运行仍需分别验证。

16:30:53 和 16:30:58 收到用户从 Indicator 发出的两次灯光命令，均返回 `completed`。读回依次为 `on:true / display_mode:fill` 与 `on:false / display_mode:status_online`；灯数始终 30，配置及手机绑定保留，水泵始终关闭。
