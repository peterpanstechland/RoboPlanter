# Indicator 工位陪伴界面

原版 SenseCAP Indicator，480×480 电容触摸屏。YOYO 继续负责自然语言交互；Indicator 提供随手可用的桌面表情、真实状态和本地番茄钟。

## 页面与手势

**可爱表情 → 今日状态 → 信息屏 → 照片屏 → 番茄钟。**

- 开机停在“工位小搭子”，轻点脸部进入今日状态。向左滑进入下一页，向右滑返回上一页，首尾不循环。
- 顶部返回键返回上一页；打开主题或硬件面板时先收起面板。
- 右上角“换个心情”在任何页面打开 8 个主题；选中立即应用并存入 ESP32 Preferences，下次开机保留。
- 手指抬起后才识别点击。横向滑动至少 60 px；触摸通信错误、多指或越界会取消这一段手势，直到真正抬手。
- 今日状态显示土壤湿度、温度、湿度和泵/灯状态；硬件操作在单独面板内。切主题、翻页、计时不会触发浇水、灯光或打印。
- 信息屏显示连接、采样距今、空气和 UV 原始数值。当前没有天气、日程或消息平台连接，因此不填充虚构信息。

表情是陪伴装饰，包含眨眼和轻微动态，不代表植物一定健康，也不是 YOYO 情绪判断。缺失或未校准的数据用 `--`；离线与旧读数始终标注。

## 番茄钟

提供专注 25 分、短歇 5 分、长歇 15 分。支持开始、暂停、继续、重置；运行或暂停期间需先重置才能更换时长。计时不依赖 Wi-Fi，翻页和换主题不会重置。完成后停在完成状态，不自动开始下一轮。

当前只在屏幕上提示完成；没有蜂鸣、手机推送或后台日程提醒。重启设备会清空当前计时，主题选择会保留。当前 MCP 工具不提供主题/番茄钟控制，也不向屏幕推送 YOYO 对话。

## 导入自己的照片

照片页默认显示空相册。当前版本支持把 1–4 张本地图片编入固件；不是手机实时传图，也不自动访问相册。需 Python 和 Pillow。

在项目根目录执行（替换为自己的图片路径）：

```powershell
python tools/pack_indicator_photos.py 'C:\Photos\窗边.png' 'C:\Photos\山野.jpg'
python tools/build_indicator_font.py --font .tools/fonts/NotoSansSC-Regular.otf
.\tools\build.ps1 -Target indicator
```

工具按 EXIF 方向旋转、居中裁切为 **400×280 RGB565**，去除 EXIF 等元数据，仅保留像素和文件名标题。每张像素约 224 KB，最多四张。照片使用前后按钮切换，左右滑动仍切换功能页。

生成的 `firmware/indicator/include/photos.local.h` 已被 Git 忽略；若把原图放入 `firmware/indicator/assets/photos/`，该目录也被忽略。照片像素会进入编译后的固件，因此分享私人固件前需检查内容。删除 `photos.local.h` 并重新构建即可恢复空相册。

源字体下载位置、许可与重生成说明见 `firmware/indicator/assets/fonts/README.md`。常规构建已经自带生成的中文字库，不必下载字体；修改中文标题或照片标题后才需重新生成。屏幕中文不等于热敏打印机支持中文，当前小票仍为 ASCII。

## 验证与实机检查

```powershell
.\tools\test-indicator-ui.ps1
python -m unittest discover -s tests -p test_indicator_assets.py -v
python tools/build_indicator_font.py --check
```

可移植测试覆盖页面边界、触摸释放/滑动隔离、无效触摸锁定、计时暂停与时钟回绕、主题与计时独立。图片测试覆盖方向、RGB565 字序、透明背景处理和错误输入保留旧包。

浏览器交互预览用于检查页面、主题和操作体验；真实字体、颜色、刷新速度和触摸方向以 Indicator 为准。烧录后需核对五页手势、八主题可读性、照片颜色、计时跨页继续，以及网络失效时的提示。当前工作只构建和测试，未烧录实机。
